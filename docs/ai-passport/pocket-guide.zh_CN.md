# 口袋景区导览 v0.5.0

给九寨沟、黄龙游客准备的离线小导览。选一个景点，读短介绍，再按需和同伴试试“小观察”。设备不运行在线 AI；AI 仅辅助编辑资料，小观察是编辑建议。

## 简短上手

1. 无需配网，首页选择九寨沟或黄龙，再选择景点。九寨沟可按区域筛选，也可直接翻列表。
2. 上下键选择项目或切换“介绍 / 小观察”；确定键进入或打开景点的更多操作，长按确定返回。
3. 更多中可标记看过、加入喜欢，在“我的足迹”查看。成功保存阅读位置后，首页出现“继续上次阅读”。两人共用一份记录。
4. 无操作 30 秒变暗、90 秒关闭背光；功能键第一次完整按下松开只点亮，再按操作。左侧独立开关键不负责点亮息屏。

## 收录内容

本版仅简体中文，共 22 个固定条目：

- 九寨沟日则沟：五花海、箭竹海、熊猫海、珍珠滩、珍珠滩瀑布、镜海。
- 九寨沟则查洼沟：长海、五彩池。
- 九寨沟诺日朗查询片区：诺日朗瀑布。它是查找分组，不是第四条主沟。
- 九寨沟树正沟：犀牛海、树正瀑布、树正群海、芦苇海、盆景滩。
- 黄龙沟：五彩池、黄龙古寺、争艳池、金沙铺地、盆景池、洗身洞、飞瀑流辉、迎宾池。

两个五彩池均显示所属景区。目录未覆盖全部景点，列表顺序不是推荐游览路线。不包含定位、导航、行程导入、实时开放/排队/天气、账号、手机 App；应用不初始化无线功能。当前通行和运营信息以景区公告、现场标识为准。

## 记录与恢复

设备仅保存看过、喜欢和最后阅读的景点 ID。内容扩充时不得重排已有稳定 ID。翻页与滚动不写存储，打开不同景点或改变标记才保存，两人共用记录。

使用独立 `pocket_guide` NVS 命名空间，两个交替的 24 字节记录包含格式版本、递增序号和 CRC-32。启动选择最新有效记录，可退回较旧有效记录；拒绝未知版本、错误 ID、截断和超界位。已有两个记录均无效时保留原数据并停写。保存失败会回退本次内存标记并提示失败，不显示成功。不自动擦除 NVS、不迁移、不联网、不访问额度星盘配对信息。

“我的足迹”中可清空，默认选取消；仅清除本导览记录。正常重启应恢复最近成功保存的内容。写入时掉电可能丢失最近一次动作；异常供电、存储损坏或完整镜像重刷可能丢失数据。主机模拟不能替代真机断电验收，不承诺跨固件保留。

## 实现与验收

- 启动入口 `main/main.c`；应用由 `guide_data`、`guide_model`、`guide_record`、`guide_ui` 组成。
- 复用 BSP、开机按键守卫、`orbit_input.h` 和 `orbit_power.h` 通用逻辑。旧额度星盘文件保留为历史，不参与本应用目标编译。
- 字体为四个字号的 Noto Sans CJK SC 子集。用 `tools/generate-guide-fonts.py --font <NotoSansCJKsc-Regular.otf> --converter <lv_font_conv>` 重生成；字形清单为 `assets/fonts/guide-characters.txt`，字体授权保留在字体素材目录。
- `./tools/validate.sh --static` 在原有测试之外检查损坏与回退、模拟写入失败、取消清空、全部 22 个景点和导航。
- `./tools/validate.sh --firmware` 构建并归档匹配的完整镜像、应用镜像和调试资料。默认分区表不变，该检查不刷写 USB 设备。
- 原生 LVGL 预览：用 CMake 配置 `tests/guide_render`，构建 `guide_render`，执行 `<构建目录>/guide_render <已有输出目录> assets/fonts/guide-characters.txt`。直接编译固件同一份界面，检查全部字形、文字安全边界/重叠与重复绘制内存。需要先安装锁定版本的 LVGL 托管依赖。

真机验收需覆盖：三键短按/长按、息屏首次唤醒不误操作、离线冷启动、两景区及同名五彩池、重启记录、取消/确认清空、写入时真实掉电、30/90 秒背光。内存余量、响应、屏幕效果和续航必须在硬件上确认。预览电量为示例，不是真实设备读数。

本地构建不包含刷写、Git 提交/推送或社区发布授权。这是独立玩法，不能把导览发布到原社区作品 1250。

## 像素版：已确认的 C 方向

0.2.0 实现作者选定的像素探险掌机：深色顶栏/底栏、奶油色阅读区、薄荷绿阶梯选中条，以及两景区各自的原创像素山水。首页显示风景条，介绍页只放小缩略图，小观察页展示较大画面；正文保持普通清晰中文。导航、记录格式、息屏行为不变，没有加入积分、等级、动效或新的无线功能。

插画与实际 LVGL 文字、状态分开；[素材来源和可复现转换](../../assets/guide/README.zh_CN.md)另有记录。六份只读 RGB565 像素合计 145,920 字节，表示景区主题，不是每个景点的实景照片。中文换行避免常见句末标点出现在行首，原生渲染会同时检查此项、文字安全区/重叠、字形和重复绘制内存。

## 按需离线讲解：v0.5.0

进入景点后按确定打开更多，选“听介绍”，返回阅读卡并播放一段离线中文讲解；仅进入景点不会自动出声。准备/播放时按确定直接取消/停止，上下键仍可翻阅读页。长按确定退出阅读并停止。播完正常结束，不自动播下一景点，不在重启后自动续播。听过不自动标记为看过，喜欢记录也独立。

工作任务处理准备、小块解码、取消和失败，不阻塞按键回调；新请求替换旧请求。失败可重试且仍可浏览，结束/停止后ES8311休眠。原30/90秒背光和息屏首次功能键仅唤醒逻辑不变，讲解不强制屏幕常亮。不录音、不上传音频。[音源、编码与重生成](../../assets/voice/README.zh_CN.md)说明22条AI合成讲解。

语音预览使用tests/guide_render/voice-preview.html及独立的build/guide-render-voice/guide_render，为tools/guide-preview.py传--renderer、--template、--audio-dir。试听WAV须通过tools/decode-guide-voice.c与tests/test_guide_voice_assets.py --wav-dir从实际固件压缩音频解出；用户点“听介绍”才发声。预览模拟播放状态，不能验收板上扬声器、驱动停止时序或休眠电流。

v0.5.0将22条扩写为作者已选A音色（zf_001），采用适合青年旅行的轻松口语、事实解释与自编观察互动。屏幕短介绍与按键保持；narration.json记录事实来源，manifest.json记录实际时长和容量。重点目标45–60秒、其他25–40秒。新候选的真机扬声器与功耗仍待验证。

## 本地交互预览

构建原生渲染器后，在已安装 Pillow 的 Python 中执行 `python3 tools/guide-preview.py --output <已有或新建输出目录>`，打开 `http://127.0.0.1:8978/`。服务仅监听本机，不访问 USB；把当前会话的按键序列交给真实 C 导航和界面代码。支持上下方向键、Enter、Esc 与页面按钮。预览中的记录及保存成功提示为模拟，不代表 NVS 或设备按键驱动通过。“重置预览”只清除预览会话。本预览不模拟真实息屏计时和唤醒。

v0.5.0补齐机上音量闭环：首页或景点更多→声音设置。上加5、下减5，范围0–100；确定试听/停止当前或上次景点，播放中调节直接应用芯片，不从头重播。长按确定停止、返回，等音频工作任务空闲后保存。独立NVS音量key不改变PG01记录；缺失/无效时默认95%，保存失败明确提示本次临时生效。0静音并停止。

保留A音色和B轻降噪基准，制作期做小扬声器语音适配：控制尖峰、收窄动态，在较高codec档位获得更高平均人声，避免只把高峰继续放大。默认95%，用户在机器上自行调节，不需逐档刷写。仍离线、主动点播。这是新增适配，不声称波形与原B或此前固定+5dB完全相同；数字电平/余量检查不代替实机听感。

息屏保持：30秒变暗，90秒关背光，首个完整功能键动作仅唤醒。音频不强制常亮。并非深睡，实际续航未测。
