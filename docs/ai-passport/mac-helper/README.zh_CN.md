## 准备

**系统版本先核对：** 0.3.3 修复了旧包带入较新系统依赖的问题，已在 Apple 芯片 macOS 14.8.9、15.7.9 完成构建与基础运行检查；14 构建产物在 macOS 27.0.1 复验通过。macOS 11–13 未做运行验收，Intel Mac 不支持。基础运行检查不替代真实配对验收；设备独立查看公开公告不受影响。

需要 Apple 芯片 Mac；安装并登录 Codex CLI，或使用安装在“应用程序”中的 Codex 桌面应用。Mac 与设备连接同一 Wi-Fi，Mac 保持开机、唤醒和联网。首次配对用 USB 数据线。

## 首次使用

1. 解压 ZIP，将 `StarshorePassport.app` 拖入“应用程序”。旧助手正在运行时先退出再替换。首次打开后，浏览器显示「随身星盘 · Mac同步助手」；若未打开，可访问 http://127.0.0.1:8942/ 。
2. USB 连接开机设备，先点电脑的「连接设备」。设备可能重启；等它回到首页后，再长按硬件确定→设置→连接 Mac，出现允许提示后按确定。
3. 电脑显示配对成功后自动同步。角色页出现个人额度，即可拔掉 USB。以后设备开机，助手会自动继续同步；若曾手动暂停，在电脑点「恢复同步」。
4. 助手首次正常运行时登记当前用户的登录启动项，可在“系统设置→通用→登录项”关闭。关闭助手不会解除配对；需要撤销授权时，在设备设置选择「解除 Mac 配对」并按设备提示确认。

## 遇到问题时

| 看到什么 | 接下来怎么做 |
| --- | --- |
| 等待连接设备／第一次同步失败 | 先完成上面的 USB 配对步骤。不要先解除已有配对。 |
| 配对未完成 | 检查数据线和设备是否开机，只连接一台 Passport；电脑点连接后，等设备启动，再在硬件设置选「连接 Mac」并确认允许。 |
| 个人额度同步未完成 | 先确认 Codex 已登录，再检查 Mac 和设备是否在同一 Wi-Fi、设备是否开机。助手会自动重试；手动暂停过则点「恢复同步」。 |
| 浏览器页面打不开，或显示其他程序 | 先确认助手正在运行；重新打开助手。若本机 8942 端口仍被其他程序占用，请反馈，不要在陌生页面输入凭据。 |
| 点击「退出助手」后 | 退出成功后显示「助手已退出」并停止刷新。关闭该页；再次打开应用可恢复运行。 |
| macOS 阻止打开 | 确认下载的是 `-notarized.zip`；记录系统原文并反馈，不关闭系统安全保护。 |

助手会分别提示尚未配对、配对记录无法读取、设备不可达或 Codex 额度读取失败；读取失败时请检查安装和登录，不代表一定已退出登录。关闭浏览器标签页不会退出助手；要停止运行，请点击「退出助手」。

## 范围与限制

- 约每 30 秒更新一次。Codex 未提供的额度窗口不会被补成零；离线或 Mac 休眠时，设备保留旧数据并标记更新时间。
- 设备重启同步及登录服务恢复已验证。2026-10-17，作者反馈现有安装的 Mac 重启和断网恢复实测正常；这不是 0.3.3 新包的重新验收。0.3.3 全新电脑首次配对、真实 DHCP 换址仍待实测。
- 社区 REV-2886 起包含设备地址发现支持；较旧 REV-2840 不含此功能。请先核对[社区版本与纯文本更新日志入口](../public-release.zh_CN.md)。地址发现已实现，但真实 DHCP 换址恢复仍待实测；某些较大网段会跳过扫描，找不到时可重新连接设备，不必先解除配对。
- Codex 登录凭据与配对密钥留在 Mac，设备只接收加密额度摘要。公开重置公告不能证明个人额度已恢复。
- 反馈请提供助手版本、固件版本、macOS 版本和操作步骤；不要发送登录凭据、配对文件或 Wi-Fi 密码。

这是额度星盘 AI Passport 的配套工具；Quota Orbit Mac 桌面主客户端另有独立安装包。本项目与 OpenAI、FoloToy 无官方背书关系。
