# 额度星盘 · AI Passport Mac 同步助手 0.3.0（预发布）

[English](README.md)

此助手把已登录 Codex 的 Mac 上可读取的个人额度，加密同步到同一 Wi-Fi 下已配对的 AI Passport。它是 Passport 配套工具，不是 Quota Orbit 桌面主客户端，也不是设备固件；不会替代或升级 Mac 主客户端。

## 下载与适用范围

- 安装包：`StarshorePassport-AppleSilicon-0.3.0.zip`（仅 Apple 芯片 Mac）
- 校验：下载同页 `SHA256SUMS.txt`，在终端运行 `shasum -a 256 StarshorePassport-AppleSilicon-0.3.0.zip` 并核对结果。
- 需要 Mac 已安装并登录 Codex CLI。Mac 与 AI Passport 必须在同一 Wi-Fi；Mac 需保持开机、唤醒且联网。
- 首次配对需要 USB 数据线和设备上的确认。以后设备开机后，助手会自动恢复周期同步；正常配对后不必每次点“开始同步”。

## 安装与首次配对

1. 下载并解压 ZIP，把 `StarshorePassport.app` 拖到“应用程序”。若正在运行旧版，先退出助手，再替换。
2. 打开助手，控制页会在浏览器出现（若未打开，可访问 `http://127.0.0.1:8942/`）。连接 USB 数据线，在 Mac 页面点“连接设备”。设备可能重启，等它回到首页。
3. 在设备上长按确定，进入“设置 → 连接 Mac”，按确定允许配对。Mac 页面显示配对成功后会自动同步；设备“角色”页显示个人额度后可拔掉 USB。
4. 首次运行会登记当前 macOS 用户的登录启动项，之后登录时尝试在后台启动并恢复同步。可在“系统设置 → 通用 → 登录项”关闭。

## 同步与兼容说明

- 助手约每 30 秒读取并推送一次额度摘要。Mac 关机、休眠或断网时不会更新；设备保留最近一次数据并标记为旧数据。
- 0.3.0 会先验证已保存的设备地址；地址失效后，在受支持的私有网络范围内尝试寻找已配对设备。自动换址需要设备也安装含发现接口的新固件。
- 社区当前公开固件尚未包含这次新增的设备发现接口；因此 0.3.0 的自动换 IP 恢复尚不能通过当前公开固件完整启用。即使助手更新，真实 DHCP 换址恢复也仍未在不同地址下实机验证。
- 设备重启后自动同步已在一台 Passport 上验证。Mac 注销／登录或系统重启后的自动启动尚未实测，欢迎反馈结果。
- 这是 Apple 芯片预览包，使用本地 ad-hoc 签名，尚未 Developer ID 签名或 Apple 公证。macOS 可能显示安全提示；请勿关闭系统安全保护。若系统不允许正常打开，请停止安装并反馈提示内容。

## 隐私与故障反馈

Codex 登录凭据与配对密钥留在用户 Mac；设备仅接收加密后的额度摘要。请勿发送账号凭据、Wi-Fi 密码、配对文件或访问令牌。反馈时提供助手版本、macOS 版本、Passport 固件版本、操作步骤和不含私密数据的截图。

解除配对请在设备“设置 → 解除 Mac 配对”中确认；这会撤销授权并清除设备上的个人额度。关闭助手不会解除配对。
