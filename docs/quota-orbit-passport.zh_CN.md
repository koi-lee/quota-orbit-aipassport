## 使用

将开机设备用 USB 数据线接到电脑，授权后写入。首次开机用手机连接设备显示的
`Starshore-…` WPA2 热点，输入屏幕密码，打开 `http://192.168.4.1`，填写 2.4 GHz Wi-Fi。
提交网络时只重新配置设备连接路由器的接口，不再主动停止整个无线模块和配网热点。
取得 IP 后才保存设置，成功或
十分钟超时后关闭热点。失败保留原有网络设置。本候选版的本地 NVS 未启用 Flash 加密。

上下切换首页、来信、角色；确定查看来信或小程序码，在角色页点亮本地星星；
长按确定打开设置或退出二维码。设置包含重新配网、提示音（默认关闭）、返回。
星星仅本次开机计数，不影响额度。

## 数据契约

每五分钟 HTTPS 读取 `https://www.starshoreai.com/quota-orbit/api/monitor`，
失败一分钟后重试。验证证书链和域名，校时前等待，不跳过 TLS 验证。
不需要云端密钥、伴侣软件或蓝牙。

流式解析 `publicInsights` schema 1 元数据与最新的 `type=reset` 事件：
`completed` 表示公开消息宣布完成，`scheduled`/`announced` 表示预告；未知类型或状态
不提升为完成。来源健康不证明公告事实准确。分类和发布时间均不证明个人额度到账，
界面提示查看原文适用范围并在自己的账号核实。

2026-10-13 样本为 167,481 字节，主机解析器状态为 2,120 字节；总响应上限 512 KiB，
嵌套上限 24 层。仅在 HTTP 成功、完整接收、结构/schema/来源时间有效且发布时间未
超过当前时间五分钟时应用。部分或损坏响应保留旧快照。来源检查超过三十分钟、
来源不健康或公告超过七天时标记过期。发布时间与设备读取时间分开展示，均为北京时间。

提示音要求已有同步基线、事件 ID/状态变化、来源新鲜健康、消息发表于此前三十分钟内。
无缓存首次开机和相同消息不响。记录改变或每半小时保存小快照，不存完整数据源。

## 配网回归修复（2026-10-13）

用户真机截图显示配网表单前返回 HTTP 403 `Use the device hotspot`。
首版只接受 AF_INET，而启用 IPv6 的 ESP-IDF 5.5.3 网页服务使用双栈监听，
lwIP 会把 IPv4 访问者表示为映射 IPv6 地址。GET/POST 现在共用子网判断，
接受 IPv4 及映射 IPv6，同时拒绝其他子网和原生 IPv6；Host/Origin 校验保留。
`test_orbit_access.c` 覆盖首版误拒绝的正确连接及越界情况，错误提示改为中文。
主机测试通过与修复版安装、真机配网成功分别记录。

## Wi-Fi 诊断候选（2026-10-13）

手机截图已验证子网修复后的表单打开和提交。后续连接失败、配网超时已确认，但未捕获
当时的无线驱动失败原因；2.4/5 GHz 同名本身不能确定故障原因。

新候选保持配网热点，连接路由器时扫描所有信道并启用两次驱动重试，每次尝试最多
等待 45 秒。每次提交重新给予十分钟配网时间。失败显示驱动原因或接口错误码；
E10000 表示已关联但未及时取得地址，E10001 表示未捕获驱动原因的连接超时。
错误码说明失败阶段，不直接证明密码或路由器有问题。应用诊断不增加凭据输出。
从未同步过的首页明确显示“尚未同步公开消息”，避免被理解为已联网但没有新消息。

完整门禁增加实际配置函数的有状态主机回归：热点保持、重试配置和接口错误传递。
原生界面检查覆盖失败和超时状态；实际无线兼容性及首次 HTTPS 同步仍待新候选真机验证。
