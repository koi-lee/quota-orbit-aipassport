# 像素山水素材

作者选定 C 视觉方向后，于 2026-10-25 使用内置 imagegen 辅助制作的原创插画，分别表现九寨沟式湖泊与黄龙式层叠彩池。它们是艺术概括，不是景点照片、地图或当前实景。两位旅人在有护栏的栈道内，没有嵌入第三方作品、Logo 或文字。

本目录保留已完成的源 PNG 和完整提示词，源图与六份转换图均已实际查看。`tools/convert-guide-art.py` 使用 Pillow 最近邻缩放、打包小端 RGB565，不重绘插画；可从任意目录执行，重生成 `guide_art.c` 和检查用 PNG。

每景区分别提供首页 240×80、小观察 216×72、阅读缩略图 72×24，合计 145,920 字节的只读 Flash 像素。LVGL 直接读取常量 RGB565 描述符，应用不额外解压全屏图片、不联网下载。实际运行内存与物理屏幕表现仍需真机验证。

22 个景点共用各自所属景区的主题插画，不把它标成单个景点的实景，例如五彩池缩略图不承诺对应精确机位。文字、选中态、页码和保存状态由真正的 LVGL 控件独立绘制。
