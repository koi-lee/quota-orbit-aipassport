# Quota Orbit character

The existing Quota Orbit web character, `web/pet-idle-poster.png`, is copied as
`archivist-source.png` for this user's companion product. It is the purple-haired
Moonlight Archivist with a crescent, cloak and book; it replaces the temporary
geometric companion. No new character or animation was generated.

The preparation script `tools/prepare-passport-assets.py` in the parent product
workspace trims transparent margins, fits the artwork to 120 × 156 pixels while
preserving aspect ratio, and encodes BGRA bytes for LVGL ARGB8888. The result is
86 × 156 pixels, 53,664 bytes stored in Flash. No PNG decoder or runtime scaling
is needed. Source transparency is retained.

This is existing user product artwork, not an upstream FoloToy asset. Reuse here
is within the requested product work; the product owner has authorized public distribution as part of the
`koi-lee/quota-orbit-aipassport` repository and its firmware package. This does
not grant a separate license to reuse the artwork outside this project. Do not
submit it to the FoloToy upstream repository.

The information-first home additionally uses a 49 × 90 px variant (17,640
Flash bytes); the character page retains the 86 × 156 px variant.

Celebration frames in orbit_celebration.c reuse the same authorized character
and product-drawn wish/sparkle particles. Generated by the workspace script
tools/render-star-celebration.py, the 49 RGB565 Flash frames contain no user data
and are neither new character artwork nor hardware screenshots.
