# 离线景点讲解

22段有来源的原创文案见narration.json，保留作者已选A音色（Kokoro v1.1-zh zf_001）与正常语速。重点45–60秒，其他25–40秒，总预算780秒。设备只播预制音频，不运行TTS、不录音、不联网/上传。

[模型卡](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)标注Apache-2.0，开发运行工具[kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx)为MIT；保留KOKORO-LICENSE.txt。模型/环境/原始WAV放仓库外，早期Mac系统声音试验未采用。

从不可变合成缓存重建：先严格复现B基准的85Hz高通、6.2kHz低通、8dB FFT降噪/-42dB噪声底、PCM16中间结果及单独+0.11dB微调。原B试听ADPCM/文本指纹在扬声器适配前继续严核。v0.5.0再进行已记录参数的语音压缩/峰值限制，目标-20 LUFS/-9dBTP；处理全部在制作期完成，保持样本数/文本，重跑不叠加过滤。manifest.json记录参数与B基准摘要。本方案替代之前固定+5dB试验。

16kHz单声道、连续4bit IMA/DVI，低半字节优先、每段预测器/索引初值0、样本数明确。固件每次解码160样本，核验芯片音量写入/读回，结束/取消休眠。声音设置支持0–100%边听边调，默认95%，另存独立音量key；Flash保存等待播放停止。

检查文件摘要、时长、峰值/静音尾、完整C解码、可选FFmpeg独立对照及对适配参考WAV的SNR。可选基准参考核对B身份及适配后语音活跃帧覆盖；逐段实际解码响度/真峰和设备送音间隔日志补充检查。这些不代表人耳自然度、扬声器实测声压或实际续航。试听WAV来自真实固件C解码器。
